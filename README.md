# Dotwel-Widgets
Nothing OS-inspired Android home-screen widgets by Dotwel Labs

## Current checkpoint

- `com.dotwelwidgets.dotwellabs`, minSdk 26, compile/target SDK 36.
- Dotwel Clock: system-updated digital `TextClock`, DotGothic16 dot-matrix type,
  red dot accent, black / translucent / transparent styles.
- Dotwel Date: system-updated day number plus weekday/month `TextClock`.
- Settings/preview activity: choose a style, see a live preview, refresh placed
  widgets.
- No INTERNET, exact-alarm, foreground-service, accessibility, overlay,
  notification-access, or location permissions.

Build with `./gradlew assembleDebug`. See `docs/ATTRIBUTION.md` for third-party
notices and `docs/agent/STATE.md` for verified status.
